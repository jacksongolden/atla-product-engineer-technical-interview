# Trace Viewer — Technical Interview

Welcome! This repository contains a Next.js application that you'll work with during your interview.

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **React Query** (@tanstack/react-query) for data fetching
- **Zod** for schema validation
- **Tailwind CSS** for styling

## Setup

```bash
pnpm install
pnpm dev
# Open http://localhost:3000/run/run_123
```

## What to Expect

During the interview, you'll:
- Debug and fix issues in the codebase
- Implement new features
- Work with URL-based state management
- Build UI components from scratch
- Discuss system design

## Preparation Tips

- Familiarize yourself with Next.js App Router patterns
- Review React Query basics (useQuery, data fetching)
- Know how to work with URL search parameters in Next.js
- Be comfortable with Tailwind CSS utilities
- Have your preferred development environment ready

## During the Interview

- Ask questions if anything is unclear
- Think out loud as you work through problems
- Focus on working code over perfection
- No tests are required

Good luck!
